# rbickel.github.io

A small, dependency-free website published with GitHub Pages.

## Customize

- Edit `index.html` to change the page content and page title.
- Edit `styles.css` to change the colors, typography, and layout.

## Publish with GitHub Pages

This site is served from the repository root. In the repository's **Settings**
under **Pages**, choose **Deploy from a branch**, select the `main` branch and
the `/ (root)` folder, then save. GitHub Pages will publish the site at
`https://rbickel.github.io/`.
